# Banking Data Analytics

SQL | Google BigQuery

## Project Overview

An end-to-end banking analytics project using SQL and Google BigQuery
to analyze customer behavior, branch performance, loan risk,
customer service interactions, and card usage.

## Business Objectives

- Analyze customer engagement and transaction behavior
- Evaluate branch performance
- Identify loan and credit-risk patterns
- Analyze customer complaints and service issues
- Evaluate card utilization and transaction behavior

## SQL Skills Demonstrated

- CTEs
- JOINs
- GROUP BY
- CASE
- Aggregate functions
- Window functions
- ROW_NUMBER()
- RANK()
- LAG()
- Date functions
- COUNT(DISTINCT)
- STRING_AGG()
